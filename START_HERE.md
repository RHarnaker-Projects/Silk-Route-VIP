# Silk Route project handover

This package contains the Silk Route website source, all media used by its current pages, the original project README and licensing notes. Begin with [setup](handover/SETUP.md), then read [hosting and access](handover/HOSTING_AND_ACCESS.md) before making changes to the live site.

- [Original project README](README.md)
- [Setup and builds](handover/SETUP.md)
- [Hosting, repository and account access](handover/HOSTING_AND_ACCESS.md)
- [Included media and excluded production originals](handover/MEDIA.md)
- [Packaging and verification](handover/VALIDATION.md)
- [Existing launch checklist](LAUNCH_LEGAL_CHECKLIST.md)
- `handover/MANIFEST.json` and `handover/MANIFEST.csv`: exact packaged files, byte sizes and SHA-256 hashes. The manifests exclude their own entries.

The source and existing documents are preserved as supplied. These handover notes take precedence when the original README describes earlier media versions. This is a local source snapshot prepared on 30 September 2026; exact equivalence to the live site's saved version has not been checked.

The package transfers files. Hosting, domain, repository and analytics access are separate owner actions described in the access notes. No credentials, browser data or account permissions are included.
